## Дипломный проект на тему "Разработка интернет-магазина товаров повседневного спроса"

Полезен для дальнейшей разработки сайта интернет-магазина в качестве шаблона. В данном проекте реализованы:
1. Со стороны пользователя:
   * Авторизация пользователя;
   * Возможность добавления товара в корзину/избранное;
   * Возможность "купить" товар/ы (не по-настоящему ofc, просто html-ка, имитирующая оплату);
   * Фильтрация товаров;
   * Личный кабинет пользователя;
   * Оставление отзыва, оценивание товара и просмотр отзывов других пользователей;
   * Поиск товаров.
2. Со стороны администрации:
   * Добавление/удаление/редактирование товаров;
   * Удаление отзывов (ну вдруг спам или что-то хуже);
   * Возможность изменить статус товара;
   * Просмотр статистики;
   * Создание и выгрузка отчетов.

## Создание и активация виртуального окружения

Windows:
```
python -m venv venv
venv\Scripts\activate
```

MacOs/Linux:
```
python3 -m venv venv
source venv/bin/activate
```

## Установка зависимостей

```
pip install -r requirements.txt
```

## Настройка переменных окружения

1. Создание файла `.env` на основе `.env.example`
2. Генерация ключа командой:
   ```
   python -c "from django.core.management.utils import get_random_secret_key; print(get_random_secret_key())"
   ```
3. Полученную строчку вставить в файл `.env` в строку `DJANGO_SECRET_KEY=[сюда надо вставить]`
